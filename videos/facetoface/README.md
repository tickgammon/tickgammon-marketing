# 🤝 Lancement du mode « Face à face »

**Sortie : dimanche 1er novembre 2026** (dates changées le 18/10/2026 ; à l'origine mercredi 18/11).
Mode amical sur une tablette posée à plat entre deux joueurs (pas d'ELO, le 2e joueur n'a pas besoin de compte).
Kit fabriqué le 23/10/2026, **en attente de validation par Joyce** (rien ne part avant).
